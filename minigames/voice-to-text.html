言霊職人

音声入力・翻訳・読み上げの道具。話すと文字になり、翻訳して、声で読み上げます。ブラウザ標準の Web Speech API を使うので、アプリのインストールもサーバーも不要です。

1音声入力（声 → 文字）

大きなボタンを押して話すだけ。聞き取り中の言葉はその場で表示され、確定した分が下のテキスト欄にたまっていきます。

待機中です
聞き取り中の言葉がここに出ます

連続入力：止めるまで聞き続けます。オウム返し：聞き取った文をそのまま声で読み上げます（マイク→認識→読み上げ→スピーカーの輪の実験用）。

🎚 入力レベル（録音タブと共通設定）

感度とメーターは録音タブと共通です。音声認識そのものはブラウザの仕組みで聞き取るため、感度は録音（議事録・ボイスレコーダー）とメーター表示に効きます。

2テキスト

音声入力の結果がここに入ります。手で打ったり、直したりもできます。

0 文字

🎧 録音ファイルから文字起こし

音声ファイルを再生しながら、マイクで聞き取って「2. テキスト」に文字起こしします。静かな場所で、音量を大きめにしてください（スピーカーの音をマイクが拾います）。

3翻訳

上のテキストを、選んだ言語に翻訳します（無料の翻訳APIを使用・ネット接続が必要。まずGoogle翻訳、ダメならMyMemoryに自動で切り替えます）。翻訳文の読み上げボタンはここ専用です。原文の読み上げは上の「2. テキスト」のボタンのままです。

テキストファイルを読み込む

読み込むと「2. テキスト」に入って、そのまま翻訳が始まります。文字コードはUTF-8とShift_JISに対応。長いファイルは先頭から30,000文字まで読み込みます。

0 文字

4読み上げの設定（文字 → 声）

声の種類と速さ、高さを変えられます。声の一覧は端末やブラウザに入っているものが表示されます。

💬 同時翻訳（会話モード）

言語ペアを決めてスタートを押すと、あとは自動で「聞き取り→翻訳→読み上げ」を繰り返します。聞き取る言語は、あなたの番と相手の番で交互に切り替わります。読み上げ中はマイクを止めるので、自分の声を拾い直しません。

🎤 聞き取り→ 🌐 翻訳→ 🔊 読み上げ→ 繰り返し

待機中です

うまく交互にならない時は「聞く言語を手動で切替」で立て直せます。会話モード中は、他のマイク機能（音声入力・録音・議事録）は止まります。

🎙 録音（ボイスレコーダー）

文字起こしなしの、ただの録音です。声メモや会議の録り溜めに。マイクや感度の設定は、文字起こし・議事録の録音とも共通です。

待機中です

🎚 入力レベル

メーターが赤まで届かない程度が目安です。録音中（または音声入力中）に動きます。

感度を上げると小さな声も拾いますが、雑音も増えます。自動調整をONにすると、声の大きさに合わせて感度が動きます（スライダーを動かすと手動になります）。

外付けマイク（USB・Bluetooth）を挿すと、ここに出てきます。名前が出ない時は、一度録音を許可すると表示されます。

OFFにすると原音のまま録れます（高音質で録りたい時・外付けマイク使用時向け）。

録音の再生と保存

ステレオ書き出しは、ステレオ録音（外付けステレオマイクなど）の時だけ意味があります。内蔵マイクは基本モノラルです。WAVは無圧縮なので大きくなります。

録音リスト（この画面を開いている間だけ）

まだ録音がありません。

📞 通話録音について

通話の音声はAndroidの仕様でWebページからは直接録れません。スマホ本体の通話録音で録ったファイルは、議事録タブの「録音ファイルを読み込む」から読み込めます。

5議事録（録音と自動文字起こし）

会議や話し合いを録音しながら、自動で文字起こしします。止めると、文字起こしが日時入りのファイル名で自動保存されます。録音した声はその場で再生でき、再生の速さも変えられます。

ピンは録音中・再生中のどちらでも打てます。一覧の時刻を押すと、その場所から再生します。

録音ファイルを読み込む

読み込んだファイルは上の再生ボタンでも聞けます。「再生して文字起こし」は、再生しながらマイクで聞き取る方式です。静かな場所で、音量を大きめにしてください（スピーカーの音をマイクが拾います）。文字起こしできたら「翻訳する（3へ送る）」で翻訳欄に送れます。

録音は端末の中で行われ、音声ファイルは自分で保存するまで残りません。文字起こしの精度は音声認識（1の機能）と同じです。長い会議では、ブラウザの音声認識が区切りごとに再開しながら続けるので、そのまま話し続けて大丈夫です。

🔊 聞きやすくする・ABリピート

議事録の再生に効く調整です（フィルター式）。声の帯域を強調したり、低音のゴーという音や雑音を抑えたりします。

人の声を聞きやすく
ノイズ・雑音除去
🔁 ABリピート

A地点：未設定／B地点：未設定

大事な発言の区間だけを繰り返し聞けます。AとBを設定してからONにしてください。

仕組みと注意

マイク→ 音声認識→ 文字→ 翻訳→ 読み上げ→ スピーカー
  • 音声認識は Chrome / Edge で使えます（Android の Chrome も可）。初回はマイクの許可が必要です。
  • 認識は Google のサーバー経由で行われるため、ネット接続が必要です。読み上げは端末内の声を使う場合がほとんどです。
  • 翻訳は無料の翻訳API（Google翻訳、予備でMyMemory）を使います。ネット接続が必要です。長い文は少しずつ分けて送っています。無料の仕組みなので、混んでいる時は失敗することがあります。機械翻訳なので、固有名詞や言い回しは意訳・誤訳になることがあります。
  • 翻訳文の読み上げは、翻訳先の言語の声を自動で選びます。端末にその言語の声が入っていない場合は、声が合わないことがあります。
  • 「PythonAnywhere」と話したつもりが、音声認識に「I saw it in a dream」と変換されてしまった、というような聞き間違いは、固有名詞・専門用語で起きやすいものです。ゆっくり、はっきり話すと精度が上がります。
  • 運転中は画面を見たり操作したりせず、停車してから使ってください。
  • このページは文字を保存しません。閉じれば消えます。残したい分は「テキスト保存」やコピーで持ち出してください。
