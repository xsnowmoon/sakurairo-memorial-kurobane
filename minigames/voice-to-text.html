音声入力・翻訳・読み上げ

話すと文字になり、翻訳して、声で読み上げます。ブラウザ標準の Web Speech API を使うので、アプリのインストールもサーバーも不要です。

1音声入力（声 → 文字）

大きなボタンを押して話すだけ。聞き取り中の言葉はその場で表示され、確定した分が下のテキスト欄にたまっていきます。

待機中です
聞き取り中の言葉がここに出ます

連続入力：止めるまで聞き続けます。オウム返し：聞き取った文をそのまま声で読み上げます（マイク→認識→読み上げ→スピーカーの輪の実験用）。

2テキスト

音声入力の結果がここに入ります。手で打ったり、直したりもできます。

0 文字

3翻訳

上のテキストを、選んだ言語に翻訳します（無料の翻訳APIを使用・ネット接続が必要。まずGoogle翻訳、ダメならMyMemoryに自動で切り替えます）。翻訳文の読み上げボタンはここ専用です。原文の読み上げは上の「2. テキスト」のボタンのままです。

0 文字

4読み上げの設定（文字 → 声）

声の種類と速さ、高さを変えられます。声の一覧は端末やブラウザに入っているものが表示されます。

仕組みと注意

マイク→ 音声認識→ 文字→ 翻訳→ 読み上げ→ スピーカー
  • 音声認識は Chrome / Edge で使えます（Android の Chrome も可）。初回はマイクの許可が必要です。
  • 認識は Google のサーバー経由で行われるため、ネット接続が必要です。読み上げは端末内の声を使う場合がほとんどです。
  • 翻訳は無料の翻訳API（Google翻訳、予備でMyMemory）を使います。ネット接続が必要です。長い文は少しずつ分けて送っています。無料の仕組みなので、混んでいる時は失敗することがあります。機械翻訳なので、固有名詞や言い回しは意訳・誤訳になることがあります。
  • 翻訳文の読み上げは、翻訳先の言語の声を自動で選びます。端末にその言語の声が入っていない場合は、声が合わないことがあります。
  • 「PythonAnywhere」が「I saw it in a dream」に化けるような聞き間違いは、固有名詞・専門用語で起きやすいものです。ゆっくり、はっきり話すと精度が上がります。
  • 運転中は画面を見たり操作したりせず、停車してから使ってください。
  • このページは文字を保存しません。閉じれば消えます。残したい分は「テキスト保存」やコピーで持ち出してください。
