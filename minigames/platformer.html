ミニ・プラットフォーマー

横スクロールアクションの仕組みを、そのまま遊べる形にした学習用ミニゲームです。 主人公はオリジナルの茶トラ猫。敵を踏み、ブロックを叩き、コインを集めて右端の旗を目指してください。全3ステージで、1面をクリアすると次の面へ進みます。 右のパネルで重力やジャンプ力を変えたり、下のエディタでステージ自体を書き換えたりできます。

毎フレーム、落下速度に足される量。大きいほど重く速く落ちる。
ジャンプした瞬間の上向き初速。放物線の高さが変わる。
横移動の最高速度。速いほど遠くまで跳べる。
全体のスロー／倍速。スローにすると物理の動きが観察しやすい。

状態モニタープレイヤーが持つ数字

—

キャラの正体はこの数字だけです。位置（x, y）と速度（vx, vy）、 そして「地面に足がついているか」の onGround。この4つ＋1フラグで全ての動きが生まれます。

仕組みのロジック（このゲームの設計図）

1ゲームループ

画面は止まった絵ではなく、1秒間に約60回「入力を読む → 状態を更新 → 描く」を繰り返した結果です。この繰り返しが全ての土台になります。

2タイルマップ

ステージは升目の設計図です。座標 ÷ タイルサイズで「その場所が何のマスか」が即座に分かるので、当たり判定が高速で単純になります。下のエディタで実際に書き換えられます。

3位置 ＋ 速度

重力で vy は増え続け、ジャンプは vy に大きなマイナスを入れるだけ。放物線は計算式ではなく、この繰り返しの結果として現れます。右のモニターで生の数字が見えます。

4当たり判定は横 → 縦

まず横に動かして壁で止め、次に縦に動かして地面に乗せる。この順番が、角で引っかかる・壁をすり抜けるといったバグを防ぎます。「当たり判定を表示」で判定枠を確認できます。

5カメラ

世界は画面より大きいので、カメラの x 座標をプレイヤーに追従させ、見えている範囲のタイルだけを描きます。背景の山や雲はカメラより遅く動かして遠近感を出しています。

6敵と踏みつけ

敵は「一定速度で進み、壁と段差で反転」するだけの状態機械です。踏みつけは「落下中 かつ 足が敵の上半分」という条件分岐で、それ以外で触れるとダメージになります。

// このゲームの心臓部（毎フレーム実行される更新処理の抜粋）
function updatePlayer() {
  // 横の入力 → 加速（地面と空中で効きが違う）
  if (keyLeft)  p.vx -= p.onGround ? 0.55 : 0.35;
  if (keyRight) p.vx += p.onGround ? 0.55 : 0.35;

  p.vy += GRAVITY;                 // 重力：落下速度が増えていく
  if (jumpPressed && p.onGround)  // 接地中だけジャンプできる
    p.vy = -JUMP_POWER;            // 上向きの初速を与える

  p.x += p.vx;  resolveX();        // 横に動いて、壁で押し戻す
  p.y += p.vy;  resolveY();        // 縦に動いて、地面に乗る（onGround更新）
}

レベルエディタタイルマップを書き換えて遊ぶ

ステージはこの文字の並びそのものです。1文字＝1タイル。書き換えて「このマップで遊ぶ」を押すと、 自分のステージで遊べます。穴を広げたり、ブロックを増やしたり、敵を並べたりしてみてください。 エディタのマップはカスタムの1面として遊びます（クリアしても次のステージへは進みません）。
