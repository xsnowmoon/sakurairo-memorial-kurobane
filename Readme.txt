プログラム内容：
　栃木県大田原市・黒羽の町を舞台にした、学園恋愛・育成シミュレーションゲームです。

　・スマホやタブレット、PCのブラウザで動き、タップ（クリック）だけで遊べます
　　アプリのインストール不要、オフラインでも動作（ゲーム本体のみ。
　　アクセス解析とWebフォントはオンライン時のみ読み込まれます）
　・私立桜丘黒羽学園の1年生として入学し、卒業までの3年間・全144週間を過ごします
　・学園の伝説「卒業式の日、屋上で告白すると恋が実る」を目指す物語です
　・ヒロインは4人
　　桜井さくら（幼なじみ）、星野あかり（テニス部のエース）、
　　月島ゆき（文芸部・図書委員。栃木弁で話します）、藤原りん（生徒会長）
　・各ヒロインに全8章の個別ストーリーと、多数の会話・イベントを用意
　・勉強や部活など14種類のコマンドでパラメータを育て、デートやプレゼントで距離を縮めます
　・セーブは端末に自動保存（複数スロット対応）。ファイル書き出しでバックアップや引っ越しもできます
　・起動時は Now Loading（読み込み進捗％表示）→「オープニングを見る／
　トップページへ進む」
　　オープニングは主題歌に合わせて黒羽の風景スライドショーが流れ、曲が終わると自動でトップへ進みます

　黒羽の見どころも登場します。
　・黒羽城址公園、黒羽図書館、黒羽芭蕉の館、那珂川の鮎、雲巌寺、五峰の湯、
　　道の駅・那須与一の郷、ホテル花月、大関和の記念碑、競走馬観世音（ライスシャワー供養塔）　ほか
　・地域イベントは全46件。長期休暇の週は地域イベントと句碑めぐりが発生します
　・松尾芭蕉の句碑めぐり（実在の全10基を順に巡ります。案内は ゆき）
　・「黒羽めぐり」チェックポイント全21か所と、実績システム
　・8月には「芭蕉の里くろばね夏まつり・市民花火大会」のイベントも
　・たまにしか出会えないレアキャラも6人登場します
　・そして、保健室の先生には秘密があるらしい……？

ファイル構成（一式で使う）：
　index.html　…画面の構造と、各ファイルの読み込みだけ
　style.css　 …全スタイル（明るい画面で固定表示）
　engine.js　 …ゲームエンジン（画面遷移・週の進行・セーブ・アルバム表示・デバッグ・
　管理メニュー・演出）
　story.js　　…ストーリー／イベントデータ（コマンドイベント・地域イベント・先生ルート・
　バッドエンド分岐）
　data.js　　 …アルバムデータ（解放条件テキスト付き）・キャラデータ・句碑データ・
　方言データなど
　endroll.txt …エンディングロールの文章（2.48〜）。
　直したい時はこのファイルを書き換えるだけ。{主人公} と書くと主人公の名前に置き換わります。
　URLもそのまま書けます
　assets/　　…画像ファイル（ヒロイン61点＋OP22点＋先生10点＋特典4点＋句碑10点＋地
　域13点＋バッドエンド20点＋ライスシャワー4点＋作者マーク等2点）
　bgm/　　　…BGMファイル（op01.mp3＝主題歌、ed01.mp3＝エンディング、
　song01〜38＝楽曲ライブラリ ほか）
　※ index.html だけでは動きません。必ず一式を同じフォルダに置いてください

BGMについて：
　・BGMは bgm フォルダ内の相対パスで指定できます（例：bgm/op01.mp3。先頭に /
　は付けません）
　・フルURLで指定することもできます。どちらもそのまま再生に使われます
　・タイトル画面の「推奨BGMに変更」を押すと、全場面（30場面）
　に歌が割り当てられます（オープニング・タイトル＝bgm/op01.mp3、
　エンディング＝bgm/ed01.mp3、修学旅行＝bgm/song01.mp3、
　デート＝song09、電話＝song10 など）。場面固定の曲は推奨BGMなしでも流れます
　・音量はタイトル画面のスライダーか、本編画面の「🔊 音量」ボタン（バーを表示）
　で調整できます（無音〜最大、BGM・効果音・読み上げ共通）
　・BGMの再生は1つの仕組みで管理しており、曲の切り替え時は必ず止めてから次を鳴らすので、
　　音が二重に鳴ることはありません
