📁 ファイル構成（一式で使ってください） 📁
　index.html　…画面の構造と、ファイルの読み込み係
　style.css　 …画面の見た目ぜんぶ
　engine.js　 …ゲームエンジン（画面遷移・週の進行・セーブ・アルバム・管理メニュー・演出）
　story.js　　…ストーリーとイベントのデータ
　data.js　　 …アルバム・キャラ・句碑・方言などのデータ
　endroll.txt …エンディングロールの文章。
　直したい時はこのファイルを書き換えるだけ（{主人公} と書くと主人公の名前に変わります。
　URLもそのまま書けます）
　version.txt …版番号だけの小さなファイル（自動バージョンチェック用）
　assets/　　…画像ファイル（ヒロイン、OP、先生、句碑、地域、バッドエンド、ライスシャワー、
　作者マークなど）
　bgm/　　　…BGMファイル（op01.mp3＝主題歌、ed01.mp3＝エンディング、
　song01〜38＝楽曲ライブラリ ほか）
　minigames/ …ミニゲームとお道具のコーナー
　QR.png　　…お友達紹介QRコードの画像
　（タイトル画面のボタンから表示します）
⚠️ index.html だけでは動きません。必ず一式を同じフォルダに置いてください

🎵 BGMについて 🎵
🎼 曲は bgm フォルダ内のパスで指定できます（例：bgm/op01.mp3。先頭に /
は付けません）。フルURLでもOKです
🎶 タイトル画面で推奨BGMを選ぶと、30場面に歌が割り当てられます（オープニング・
タイトル＝op01、エンディング＝ed01、修学旅行＝song01、デート＝song09、
電話＝song10 など）。場面固定の曲は推奨BGMなしでも流れます
🔊 音量はタイトル画面のスライダーか、本編画面の「🔊 音量」ボタンで調整できます（無音〜最大、
BGM・効果音・読み上げ共通）。テスト音も鳴らせます
🔇 曲の切り替えは必ず止めてから次を鳴らす仕組みなので、音が二重に鳴ることはありません♪

🎬 動画について 🎬
🎬 イベントの場面で「🎬 動画再生」ボタンが出ることがあります（対応動画がある場面だけ）。
回想アルバムの「🎬 動画コレクション」からも見られます。
📂 動画ファイルは本体に入っていません。index.html と同じ場所に videos
フォルダを作って動画（date-sakura.mp4 など）を入れると再生できます。
無くてもゲームはそのまま遊べます。

☕ 余談 (´ε｀ )
もともとは「AIの手も借りて、ゲームを1本作ってみよう」という試みで、
基本部分は3〜4時間ほどで出来上がりました。
その後、舞台を作者の地元・大田原市黒羽に置き換えて、実在の名所やお店、
芭蕉の句碑を巡る仕掛けを足していったら、気づけば「黒羽の観光ゲーム」になっていました。
この仕組みは他の町でも使えます。「あなたの街の観光名所ゲーム作ります。
町のオリジナルソングも作ります。しかも無料」みたいな感じで・・・・
